# 🎮 Tetris

A modern, responsive Tetris game built for both desktop and mobile devices, featuring multiple difficulty levels, smooth controls, score tracking, next-piece previews, and a clean retro-inspired interface.

# 📌 About the Project

Tetris is a browser-based implementation of the classic block-stacking puzzle game.

The goal is simple: arrange falling blocks to create complete horizontal lines and clear them before the board fills up.

This project was built with a focus on creating a smooth and enjoyable gaming experience across different screen sizes, while maintaining a clean and visually appealing interface.

The game supports both **keyboard controls on desktop** and **touch-friendly controls on mobile devices**, allowing players to enjoy Tetris wherever they are.

# ✨ Features

## 🧩 Classic Tetris Gameplay

* Falling tetromino pieces
* Move pieces left and right
* Rotate pieces
* Soft drop functionality
* Line clearing
* Game-over detection
* Continuous piece generation

---

## 🎯 Difficulty Levels

Choose your preferred difficulty before starting the game.

* Easy
* Medium
* Hard

Each difficulty level changes the falling speed of the pieces, allowing both beginners and experienced players to enjoy the game.

---

## 📊 Score Tracking

* Real-time score updates
* High score tracking
* Score displayed during gameplay
* High score displayed alongside the game board

---

## 👀 Next Piece Preview

A dedicated preview area shows the upcoming tetromino, allowing players to plan their next move and play more strategically.

---

## 🎮 Responsive Controls

### Desktop

Keyboard controls allow quick and precise gameplay.

* ← Move left
* → Move right
* ↓ Soft drop
* ↑ Rotate

### Mobile

A dedicated touch-control interface provides easy access to the main gameplay controls.

```text
              ↻

         ←    ↓    →
```

The controls are centered and optimized for touch interaction on mobile devices.

# ⚡ How to Play

1. Open the game.
2. Select a difficulty level.
3. Click **Start**.
4. Move and rotate the falling pieces.
5. Complete horizontal lines to clear them.
6. Continue clearing lines to increase your score.
7. Try to beat your high score.
8. If the blocks reach the top of the board, the game ends.
9. Restart and try again.
